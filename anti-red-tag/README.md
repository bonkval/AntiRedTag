# Anti Red-Tag

Keeps one selected tab reporting visible and focused while you work elsewhere.

## Install

1. Extract the downloaded ZIP.
2. Open your browser's extensions page:

   | Browser | Address |
   | --- | --- |
   | Opera / Opera GX | `opera://extensions` |
   | Chrome / Chromium | `chrome://extensions` |
   | Edge | `edge://extensions` |
   | Brave | `brave://extensions` |

3. Turn on **Developer mode**.
4. Click **Load unpacked** and choose this **anti-red-tag** folder containing `manifest.json`.
5. Pin the extension to your toolbar.

Keep this folder in place after installation. Firefox and Safari are not supported.

## Use

Open a website, click Anti Red-Tag, choose your tab, and press **Power**. Allow website access when asked.

- **Power:** turn protection on or off.
- **Red stop icon / Alt+Shift+K:** emergency stop.
- **Reload icon after stopping:** reset the page if old protection remains. Unsaved edits may be lost.

Protection is best effort; some website and browser signals cannot be blocked.

## Update

Replace the files in this folder, then click **Reload** on the extension's card in your browser's extensions page. Disable any older copies.
